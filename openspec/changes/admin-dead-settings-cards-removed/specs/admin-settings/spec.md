# admin-settings Delta: admin-dead-settings-cards-removed

## ADDED Requirements

### Requirement: No admin card promises what it does not do

An admin settings card SHALL NOT show text saying a later delivery will fill it, and SHALL NOT offer only settings that nothing reads.

#### Scenario: Mandate matrix settings
- GIVEN the Geavanceerd tab
- THEN there is no "Mandaatmatrix: systeeminstellingen" card, and no card reads "Dit paneel zal … bevatten"
