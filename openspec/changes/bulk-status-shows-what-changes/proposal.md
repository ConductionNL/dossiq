# The status dialog shows what changes

## Why
Board DqZakenBulkactie opens the bulk status dialog with a table of what changes per case and one button that runs the act. The dialog asked for a status and a reason first, then rehearsed on a second screen, and offered the transitions of the first case only.

## What changes
- The picker offers the transitions every selected case offers.
- The dialog lists each selected case: now, becomes, term.
- The primary button still rehearses first. A rehearsal that covers exactly the cases in the table, with every case ready, runs at once. Any skip, refusal or wider selection stops at the progress panel, as before.
- A job that changed every case ends on a result panel naming each case.
- Suspend, resume and extend keep their rehearse step.
