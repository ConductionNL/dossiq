# Proposal: lists-let-the-reader-choose-columns

## Why

Capability row 9.5 (user column chooser on lists) is built: the Cases list mounts the index side panel, and its
Columns tab turns columns on and off. No requirement said so, so the row could not record one.

## What changes

A requirement in `case-search-and-lists` that states the behaviour the Cases and Tasks lists already have. No code
changes.

## Scope

Spec only.
