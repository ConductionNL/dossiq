## Why

Base Register Seed Data Specification is not yet implemented in Procest. This change proposes adding this capability based on the detailed spec in `specs/base-register-seed-data/spec.md`.

**Feature tier**: MVP (BRP + KVK + BAG), V1 (DSO + ORI)

## What Changes

See `specs/base-register-seed-data/spec.md` for full requirements and scenarios.

## Impact

- **Code**: New frontend views and/or backend services
- **Dependencies**: OpenRegister (data storage), Nextcloud platform APIs
- **Testing**: Unit tests for new services, integration tests for API endpoints
