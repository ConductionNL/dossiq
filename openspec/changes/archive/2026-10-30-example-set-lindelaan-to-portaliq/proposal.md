# Proposal: example-set-lindelaan-to-portaliq

## Why

The Zuiddrecht example set wrote two "Verlichting fietspad Lindelaan" Woo cases: portaliq's, the request the portal
resident Sanne de Vries made through Mijn Zuiddrecht, and dossiq's, with Linda Bakker as requester. The DqZaak boards draw
Sanne's (Ruben, 20 October 2026). Dossiq's carried the contact moments, documents, tasks and advice the boards draw.

## What changes

Dossiq's fragment drops its Lindelaan case and everything on it; portaliq's fragment carries them on Sanne's case
(portaliq `example-set-sanne-cases`). The Woo document type stays in dossiq's fragment, with a description only it
carries ("Document bij een Woo-verzoek"), so portaliq's documents find it by lookup and the demo data's "Woo-document"
type cannot match.
