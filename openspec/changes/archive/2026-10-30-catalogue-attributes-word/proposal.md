# Proposal: catalogue-attributes-word

## Why

Board DqCatalogus names the attributes folder "Attributen". The key "Attributes" reads "Kenmerken" in Dutch, and
board DqZaaktypeStatussen keeps "Kenmerken" for the fields a case type offers (the blueprint card), so one translation
cannot serve both (coordinator decision, 23 Oct).

## What changes

The catalogue's attributes folder reads its own key "Attributes (catalogue)": English "Attributes", Dutch "Attributen".
"Attributes" keeps "Kenmerken" everywhere else.

## Reach

Config and l10n only.
