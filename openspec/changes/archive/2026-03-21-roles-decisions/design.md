# Design: Roles & Decisions

## Architecture
- **Roles**: Participant-case relationships (handler, advisor, decision-maker) stored in OpenRegister
- **Results**: Formal case outcomes linked to result types controlling archival rules
- **Decisions**: Formal administrative choices with legal validity periods and publication
- **Components**: `ParticipantsSection.vue`, `ResultSection.vue`, `AddParticipantDialog.vue`
