# Proposal: linked-card-fees-noun

## Why

Board DqZaak "Gekoppeld" (r41) closes with "Leges en betalingen, contract en projecten: niets gekoppeld", as `openspec/specs/case-linked-card/spec.md` already requires. Live read "Financiële documenten, contract en projecten: niets gekoppeld": the card takes each leaf's own noun, and shillinq's finance leaf, which serves every app, calls itself "financial documents".

## What changes

Both case profiles list the finance leaf as `{ "id": "shillinq-financial-documents-panel", "noun": "fees and payments" }`, so the card names it in the case's words (nextcloud-vue linked-leaf-noun-from-host). "fees and payments" is translated "leges en betalingen". No requirement changes: this brings the page to the existing scenario.
