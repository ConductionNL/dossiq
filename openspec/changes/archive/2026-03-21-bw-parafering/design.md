# Design: B&W Parafering

## Architecture
- **Pattern**: Ambtelijk workflow for preparing, reviewing, approving proposals for College van B&W
- **Backend**: Parafering entity stored in OpenRegister, linked to cases and decisions
- **Frontend**: Parafering workflow UI with approval chain
- **Integration**: Connector to external RIS systems (iBabs, NotuBiz) for bestuurlijk decisions
