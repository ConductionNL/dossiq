# woo-case-type Specification

## Problem
Provide a standard zaaktype template in Procest for handling WOO (Wet open overheid) requests. Pre-configured workflow covering the full lifecycle: intake, document search, assessment, redaction, and publication. Links to Docudesk anonymization for document redaction.

## Proposed Solution
Implement woo-case-type Specification following the detailed specification. Key requirements include:
- Requirement 1: WOO zaaktype template activation
- Requirement 2: WOO lifecycle stages
- Requirement 3: WOO-specific intake form
- Requirement 4: WOO deadline tracking and extension
- Requirement 5: Document collection and inventory

## Scope
This change covers all requirements defined in the woo-case-type specification.

## Success Criteria
#### Scenario 1.1: Activate WOO zaaktype from template library
#### Scenario 1.2: Customize template before activation
#### Scenario 1.3: Template includes version metadata
#### Scenario 1.4: Template ships as JSON seed data
#### Scenario 1.5: Multiple templates can coexist
