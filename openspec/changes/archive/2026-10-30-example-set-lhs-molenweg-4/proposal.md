# Proposal: example-set-lhs-molenweg-4

## Why

DqHandhaving draws an LHS recommendation for Molenweg 4, made by Lars de Koning: a serious violation, advice a penalty order (last onder dwangsom). The set's only recommendation is on Schuur Molenweg 3, and another on :8080 points at a case that does not exist.

## What changes

- An `lhsRecommendation` on the set's Molenweg 4 case, by Lars de Koning: severity ernstig, a penalty order, against the shipped matrix (version 1).

## Not in this change

Each needs configuration or a case type, not example data:
- the board's matrix "versie 2";
- a dedicated enforcement case ("Handhaving Molenweg 4", from the VTH package, which installs on request);
- the behaviour "onwetend" the board shows, which the LHS vocabulary does not have.
