# case-list-handler-chip-28 Delta

**Status**: proposed
**Scope**: dossiq

## ADDED Requirements

### Requirement: The case list handler chip is 28px

The case list SHALL draw the handler's initials as a 28px chip, in the table and in the cards' footer.

#### Scenario: DqZaken

- GIVEN a case handled by Pieter Jansen
- THEN the Behandelaar cell shows a 28px "PJ" chip
