# example-set-buurtvereniging-oost

## ADDED Requirements

### Requirement: Buurtvereniging Oost has its cases and contact moments

The Zuiddrecht example set SHALL hold the company Buurtvereniging Oost and its chair Marja Verbeek, three cases with the association as requester (one in decision, two closed), and four contact moments naming the association.

#### Scenario: The organisation page
- **GIVEN** the set is installed
- **WHEN** a handler opens Buurtvereniging Oost
- **THEN** its three cases and four contact moments SHALL be listed
