# Proposal: task-description-in-side-card

## Why

Board DqTaak draws no Omschrijving card: the Overview holds Checklist, Afspraken and Notities. Live drew a
Description card above them (r25b, extra on live). The coordinator decided on 24 Oct to follow the board and
move the description into the Taak side card, so nothing is lost.

## What changes

The `task-description` card is gone from the Overview. The side Task card opens with the description as a line of
text (`as: "text"`), and an empty description draws nothing. Config only.
