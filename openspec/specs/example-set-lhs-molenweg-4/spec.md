# example-set-lhs-molenweg-4 Specification

## Purpose
What dossiq does for example set lhs molenweg 4. The requirements were first written by the change `example-set-lhs-molenweg-4` (archived 2026-10-30 under `openspec/changes/archive/2026-10-30-example-set-lhs-molenweg-4/`) and cover: Molenweg 4 has its LHS recommendation.

## Requirements

### Requirement: Molenweg 4 has its LHS recommendation

The Zuiddrecht example set SHALL hold an LHS recommendation on its Molenweg 4 case, made by Lars de Koning, for a serious violation, advising a penalty order.

#### Scenario: The recommendation page
- **GIVEN** the set is installed
- **WHEN** an administrator opens the recommendation
- **THEN** it SHALL name the Molenweg 4 case, Lars de Koning and the penalty order
