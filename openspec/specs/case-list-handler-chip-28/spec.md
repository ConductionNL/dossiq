# case-list-handler-chip-28 Specification

## Purpose
What dossiq does for case list handler chip 28. The requirements were first written by the change `case-list-handler-chip-28` (archived 2026-10-30 under `openspec/changes/archive/2026-10-30-case-list-handler-chip-28/`) and cover: The case list handler chip is 28px.

## Requirements

### Requirement: The case list handler chip is 28px

The case list SHALL draw the handler's initials as a 28px chip, in the table and in the cards' footer.

#### Scenario: DqZaken

- GIVEN a case handled by Pieter Jansen
- THEN the Behandelaar cell shows a 28px "PJ" chip
