# Screens

The flow screens are one set (decision 379, 5 Nov 2026): the canonical boards live under OpenRegister, and an app's flow board is a variant that imports the shared parts with the app's own example flow, step types and wording.

- dossiq/DqTaak taak https://identity.conduction.nl/screens/board?id=dossiq/DqTaak
- dossiq/DqTaken taken https://identity.conduction.nl/screens/board?id=dossiq/DqTaken
- dossiq/DqZaak zaak https://identity.conduction.nl/screens/board?id=dossiq/DqZaak
- DqFlow: the case type flow in canvas mode with the validation messages and the refusal of a form the performer could not fill; variant of the canonical set, imports OrFlowKop, OrFlowPalet, OrFlowCanvas, OrFlowStap https://identity.conduction.nl/screens/board?id=dossiq/DqFlow
- DqZaaktypeFlow: the same case type flow in list mode: statuses and the steps per status; variant of the canonical set, imports OrFlowKop, OrFlowStappenlijst, OrFlowStap https://identity.conduction.nl/screens/board?id=dossiq/DqZaaktypeFlow
- openregister/OrFlow: the canonical editor these variants follow https://identity.conduction.nl/screens/board?id=openregister/OrFlow
